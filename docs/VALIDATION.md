## 验证范围

实际付费 API 验证使用 DeepSeek；其他兼容服务只进行了协议模拟测试，不能据此保证每个模型的图片能力和输出质量。多模态识读与第二次模型审校仍可能出错，尤其是手写疑点、概念边界与例题推理。工程测试不证明学习效果或所有生成内容都正确。

LibreOffice 未在本机安装，旧 Office 真实转换未验证；缺依赖、进程超时与错误路径已有测试。应用定位为本机单用户工具，没有公网多用户权限隔离。
