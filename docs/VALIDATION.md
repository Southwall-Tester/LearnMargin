# 验证记录

本轮开发在 Windows / Python 3.13 / Chromium 上完成，日期为 2026-10-04。CI 会另外检查 Linux 环境。

- Python：145 项测试通过，覆盖文档解析、范围、两个 API 协议、任务状态、凭据边界、手写转录和真实 PDF 渲染。
- 前端：13 项测试通过，生产构建通过，npm audit 无已报告漏洞。
- 真实浏览器：文件导入、范围选择、内置示例生成、PDF 与 ZIP 下载通过；网页打开主材料与参考资料后，返回保留 iframe DOM、滚动位置和按钮焦点；390 px 窄屏无页面横向溢出。未发现 JavaScript 运行错误。
- 真实模型：默认 DeepSeek 完成两份自编资料的页码范围和知识点范围生成；逐文件来源说明、引用角色和来源导航均有实际产物。手写中文、分数和几何式的三个公开小样本经过真实视觉识读与人工对照，详见 [OCR.md](OCR.md)。
- PDF：检查 A4 与宽版尺寸、公式、分页、正文保留，以及侧栏到参考答案、答案回原侧栏的实际目标页和坐标。HTML 无需 CDN。
- 软件包：从 sdist 构建 wheel，在仓库外隔离环境安装，验证前端资源、健康接口与无 API 示例生成；示例为 5 页 A4。安装包不包含浏览器，使用预先安装的 Chromium 和系统字体。
- Skill：18 章方法库、相对链接及独立打包检查通过；技能包没有原始 EPUB、私人课件、密钥或生成记录。

## 验证范围

实际付费 API 验证使用 DeepSeek；其他兼容服务只进行了协议模拟测试，不能据此保证每个模型的图片能力和输出质量。多模态识读与第二次模型审校仍可能出错，尤其是手写疑点、概念边界与例题推理。工程测试不证明学习效果或所有生成内容都正确。

LibreOffice 未在本机安装，旧 Office 真实转换未验证；缺依赖、进程超时与错误路径已有测试。应用定位为本机单用户工具，没有公网多用户权限隔离。
