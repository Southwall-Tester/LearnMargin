# 课本补充：条件概率的适用前提

这份自编课本摘记与 probability.md 配套，供多资料检索验证。

当 P(B)>0 时，条件概率 P(A|B)=P(A∩B)/P(B)。如果用人数比计算，还须说明抽样是在原样本空间中等可能进行的；若个体被抽中的概率不同，就不能直接用人数相除。

可以把 B 想成新的观察窗口：原来只占全体一部分的交集，在 B 内重新比较大小。P(A|B) 的分母是 P(B)，而 P(B|A) 的分母是 P(A)。两者的交集相同，参照范围不同。

事件独立采用乘法判据 P(A∩B)=P(A)P(B)，这个定义不需要条件概率的分母非零。当 P(B)>0 时，它才等价于 P(A|B)=P(A)。当 P(B)=0 时，不能套用该条件概率除法公式来判断独立。

互斥讨论交集是否为空；独立讨论概率乘法关系。两个概率都大于零的互斥事件不独立；零概率情形不能忽略。

这份资料提供的是前提和边界解释，与另一份材料中的人数例题互补，不包含新的学习效果数据。
