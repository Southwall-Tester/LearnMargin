谓词逻辑 · 学习总览先看全局 / 00

先建立地图，再进入细节

这部分学习的核心，是正确处理“所有”“存在”以及它们之间的关系。你将学会两类操作：把公式等价地整理成统一形式，以及根据带量词的前提证明结论。两者都要求跟踪变量由谁约束、对象怎样选取。

一张地图：四个部分各自解决什么问题

① 前束范式 · 整理表达把量词集中在最前面，母式不含量词，公式含义保持不变。主要操作：去箭头 → 推否定 → 改名 → 外提。正文 1～4 页。
② 有效结论 · 确定证明标准只要前提全真，结论就不能为假；反例要让前提全真而结论假。用直接推导、逆否或反证组织证明。正文 5 页。
③ 量词规则 · 连接一般与个体US、ES 让我们讨论对象；EG、UG 把满足条件的结果推广成量化结论。核心限制：代入合法、见证新鲜、推广有任意性。正文 6～9 页。
④ 完整推理 · 组合规则选择对象 → 进行命题逻辑推理 → 得到目标结论，同时检查量词顺序与见证依赖。比较错例、修复证明，并独立自测。正文 10～12 页。
怎样衔接：前束化帮助你看清量词与辖域；有效性规定“怎样才算推对”；量词规则与命题规则一起构成证明。自然推理并不要求先把每个前提都化成前束范式。

先记住轮廓：四条规则的职责

规则直观作用最需要检查的条件
US所有对象成立 → 指定一个也成立代入不能导致变量捕获。
ES有对象成立 → 给见证一个新名字新见证的范围与依赖必须保留。
EG已有一个实例 → 至少存在一个替换及新量词的辖域要合法。
UG对任意对象均已证明 → 全体成立不能依赖该对象的特殊假设。

贯穿全篇的三个区别

等价与推出：前束化要求双向等价；证明中的一步可以只是单向推出。

外提与合并：“且”不自动阻止量词外提；两个存在命题也不保证共用见证。

各自存在与共同存在：∀x∃y 允许 y 随 x 改变；∃y∀x 要求同一个 y 适合全部 x。
