# 可复用的生成入口

## 默认：A4 纸张内的正文与侧栏

新讲义默认纸张为 210 × 297 mm。正文与侧栏都放在纸张内，主文约三分之二、侧栏约三分之一；正文约 10.5～11 pt、侧栏约 9.5 pt。按内容增页，不裁切、不为了固定页数压缩字。侧栏允许为空，正文中没有值得提示的难点时不凑数。

由当前对话 AI 直接编写讲义，使用宿主现有的 PDF／文档工具，或生成本地 HTML/CSS 后导出。无需安装 LearnMargin 软件、配置 API 或导入软件 Python 模块。所需学习方法在技能包内；排版工具按当前环境选择。

HTML/CSS 方案使用 `@page { size: A4; }` 和纸张内双栏，内容块自然分页或测量后分页，保持提示与对应段落相邻。公式使用宿主提供的数学排版工具、可用的本地公式资源或其他经过验证的排版方式，不把未处理的 LaTeX 当成成品。最终仍需提取 PDF 文字并视觉检查，不能只检查 HTML。

需要作答的侧栏提供非空参考答案并统一后置；纯操作不硬配答案。按任务实质判定，不按“动笔”“重做”等标签分类。若复用已有例题解答，提供明确的核对及返回入口；不能用模糊的“对照正文”替代可定位的答案。已有答案时，可能泄露答案的核对文字也一起后置。以稳定编号连接卡片与答案，并核对 PDF 双方目标页与实际坐标。内容可用 HTML、JSON 或宿主文档格式保存，不要求遵循另一软件的内部数据模型。

多资料在相应章节展示各自论述与关系，来源区分主材料、参考资料和主题相关资料。PDF 保持独立阅读，来源可以跳到讲义内的来源表。宿主若支持查看原材料，可额外提供往返入口；独立 HTML 和打印版本不显示依赖特定宿主的按钮，不生成本机绝对路径。

手写或扫描件使用可用的多模态识读或 OCR 工具，逐页保留原图、转录和疑点。不要把转录文本替换原图作为唯一证据；生成前仍要复核数学结构与来源。休息提示等辅助文字也可能包含公式，应经过同样的公式渲染检查；检查标题孤页、休息卡孤页与窄屏公式溢出。

休息卡属于学习侧栏，和对应的完整内容块保持同页，不单独挤到下一页顶端。先依据内容负荷安排停顿，再分页；渲染器不按页数增加休息点，不要求每章和尾段都有卡。记录各点对应的学习任务、用时估计依据和最终位置，检查相邻点是否只隔几道轻量练习；出现这种情况应合并学习段。更换字号或版式不改变学习任务与休息安排，不能截断证明强行插卡。相同停顿只显示一份提示，保留实际计时条件、休息时长和就地接续动作。

下面两个独立脚本是**保留源 PDF 版式的可选工具**。它们会扩宽纸张，不能用来实现默认 A4 内栏；只有明确需要保留源页或用户选择宽版时采用。旧示例 `assets/overview-example.html` 展示的是这一可选宽版，不能直接当作 A4 模板。

## 可选：保留源页，向外添加侧栏

依赖 Python、PyMuPDF、Playwright 及可用的 Chromium。先检查环境；缺少时说明需要的依赖或使用已有等效工具，不把本机环境当成所有机器都具备。

### 使用旧脚本重排正文

1. 阅读源材料并编写详细正文 HTML。可引用 `assets/handout.css`，用 `<section class="page">` 划分计划页，放置定义、步骤、公式、表格与例题。CSS 是模板，不包含固定学科内容。复杂公式使用已验证的本地公式排版或矢量渲染，不能把未处理的 LaTeX 当成排版完成。
2. 运行 `python scripts/render_html.py --input body.html --output body.pdf --report body-check.json`。长页应重新分段，不能为凑页数随意缩小字号。
3. 为实际正文编写总览与侧栏，执行下面的“已有 PDF”流程。

### 已有 PDF

先阅读 PDF 并映射真实页码。脚本保留源 PDF 页面作为左侧矢量内容，在右边加入侧栏，在开头插入总览，并将需要作答的卡片答案排在末尾：

```text
python scripts/add_sidebars.py --source body.pdf --notes sidebars.json --overview overview.html --output guided.pdf --report validation.json --preview-dir previews
```

输入、输出必须是不同路径。默认生成约 78 mm 的右栏，原字号保持不变；可通过 JSON 的 `sidebar_width_mm` 调整。对于短横向幻灯片、极窄页或特殊版式，优先重新排讲义或调整脚本，不能强塞默认侧栏。

题答往返默认以 125% 缩放定位到目标卡片。用 `--navigation-zoom 1.5` 调整为 150%；接受 `0.25`～`4`，或用 `--navigation-zoom 0` 保留阅读器当前缩放。整页适配时，即使目标坐标正确，整页仍可能全部可见，看起来只有翻页；显式阅读缩放让目标位置更清楚。最终效果仍需在实际阅读器中确认。

### 总览模板

`assets/overview-example.html` 是完整的谓词逻辑示例，用于展示内容地图、规则摘要、学习顺序和学习侧栏布局。它不是其他主题的默认内容。使用时必须按新材料重写标题、概念、关系、阶段、目标、来源与页码，不能把示例里的学科结论带到新讲义。

当前脚本支持这个单页模板的 `.sheet`、`.meta`、`aside .card`、`.aside-foot` 结构，并检查边界。模板尺寸应与“原正文宽度 + 侧栏宽度、原正文高度”对应。大范围课程可以另设计多页总览并调整渲染入口；技能本身不要求所有总览都只能一页。

### 侧栏 JSON

```json
{
  "title": "本讲义的标题",
  "version": "试用版 01",
  "method_source": "依据学习之道第4、7、18章设计；练习为本材料配套内容",
  "sidebar_width_mm": 78,
  "pages": [{
    "page": 1,
    "title": "这一正文页的标题",
    "goal": "明确本页要理解的内容",
    "cards": [{
      "id": "1A",
      "kind": "question",
      "anchor": "真实出现在源PDF中的小节标题",
      "label": "读完本节 · 回想",
      "title": "具体的学习动作",
      "body": ["针对该概念的具体提问。"],
      "answer": ["这条任务的简短参考答案或判断要点。"],
      "check": "需要时补充核对依据；随答案后置。",
      "response_lines": 2
    }],
    "footer": "下一次回想或当前使用提醒"
  }]
}
```

`pages` 应依次覆盖源正文的全部页面。每页 `cards` 可以为空；不要为没有意义的页面硬塞任务。存在 `anchor` 时必须在真实 PDF 中匹配；扫描件或特殊布局可用经视觉确认的 `anchor_y_pt` 代替，单位为从页面顶部起算的 PDF 点，不能随意猜测。

新卡片明确填写 `kind`：`question` 必须有非空 `answer`（字符串或段落字符串列表）；`action` 用于纯操作，不填写答案。为兼容旧数据，未声明 `kind` 的卡片仍按 `action` 渲染，并列入报告的 `legacy_untyped_cards`；这不表示脚本确认了它们属于纯操作。脚本不根据任务词语猜测类型，作者须检查这些旧卡片中是否夹有遗漏答案的题目。其他工具的 `requires_answer` 字段须迁移到 `kind`，脚本会拒绝静默忽略它。`id` 在整份讲义中唯一。可选 `check` 与 `answer` 接受相同文字格式：题目的 `check` 随答案后置，操作提示的 `check` 就近显示。不要把答案预先写入 `body`。

脚本为题目卡片添加“查看参考答案 →”，将答案排入末尾独立页面，并从“← 返回这条提示”定位回原卡片坐标。短答案按实际高度分页；单条答案超过一页会明确报错，改用支持长答案自然续页的排版方式，不裁切。若原例题已有答案，可将对应答案或必要判断要点填入 `answer`；使用其他排版工具时也可直接复用现成解答的双向锚点。最终报告的 `sidebar_navigation` 记录并校验每对链接的页码、坐标与 `zoom`，`navigation_zoom` 为所选阅读缩放，`answer_pages` 为后置答案页数。

### 番茄休息提示

在合适的页面对象中加入可选 `pause`，脚本会把该页侧栏底部显示为醒目的休息提示，并给正文卡片留出空间。不要每页都添加：

```json
"pause": {
  "minutes": 5,
  "when": "若距上次休息已专注约25分钟，休息5分钟；时间未到可继续。",
  "activity": "放下材料，起身喝水。",
  "resume": "回来先回想外提条件，再读正文第3页。"
}
```

休息提示替代该页普通 `footer`；重要的原页脚信息应并入恢复动作、其他提示或后页。检查休息提示没有遮挡卡片，时长与触发文字一致，接续页码有效，并在总览说明计时到时不必硬撑到指定页。

## 验证与交付

- 查看源 PDF 与输出的文字、渲染和结构检查报告。正文保留检查不能证明侧栏内容正确，仍需检查任务与内容的对应关系。
- 预览总览和全部侧栏，查看字体、公式、溢出、答案提前暴露和阅读密度。
- 增加总览后，维护页码引用。脚本保留原正文编号并移动书签目标。
- 跨页提示以最终 PDF 实际页序为准，正文编号如需保留写在括号中，例如“PDF 第 12 页（正文第 11 页）”。插入总览后重新检查全部引用；优先使用可点击锚点。侧栏与后置解答要有清楚的“查看参考答案 →”／“← 返回这条提示”按钮式链接，返回具体卡片，不能跳整章页首。PDF 检查必须核对双向链接的实际目标页与坐标，而不只是链接数量。
- HTML 锚点可能导出为命名目的地；脚本解析其真实页码与坐标，再转换为内部跳转。查看报告的 `internal_links_preserved`，核对练习到答案及返回链接的目标；不能仅检查正文文字保留。
- 保留内容 HTML、侧栏 JSON、生成入口和验证记录于项目目录，不把用户教材或完整原书打包进 skill。
