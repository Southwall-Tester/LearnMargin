# LearnMargin · 总览与侧栏讲义

由当前对话中的 AI 直接把用户材料制作成学习 PDF，让学习者先理解全局、再逐步理解与练习。学习指导应与具体内容相邻，不能只另交一份通用学习方法清单。本技能是独立产品，包含所需的方法知识库，不要求安装 LearnMargin 软件、提供 API Key 或持有原 EPUB。独立的软件产品也复用这些方法资料，但不是使用本技能的前置条件。会话使用说明见 [USAGE.md](USAGE.md)。

## 必须保留的产品约定

- **开头由 AI 编写实质性的内容总览。**总结这一段在解决什么问题、主要概念、概念之间的关系、整体知识结构、建议学习顺序与每阶段的可观察目标，并给出正文导航。总览不是只有目录，也不能把工作推回给初学者，让其自行浏览、总结未学内容。
- **正文完成教学，而不止复述材料。**材料确定学习主线与结论依据，其篇幅和省略不限定讲解深度。补清理解当前内容所需的定义、条件、直觉、推导与例子，先帮助理解，再要求回想；不能以“本页未展开”为由只报结论或让初学者自行查找。推理前提在使用前说明，数学例题保留关键中间步骤及理由；补充深度按学习目标决定，具体做法见 [references/learning-design.md](references/learning-design.md)。
- **输出语言独立于材料语言。**优先遵循用户选择，未指定时沿用对话语言，不因材料为英文就生成英文讲义。总览、正文、侧栏、答案、休息提示及导航文字保持所选语言；保留必要原文术语、代码和引用。
- **专业缩写首次出现时解释。**给出经材料核验的原文完整名称，并用输出语言解释含义，后文可用缩写。不凭字母猜全称；仅全称无法核实而定义已有依据时，解释定义与用法，只标明全称未核实，不能因此省略教学。
- **学习指导放在需要采取行动的位置。**侧栏既可检验知识，也可指导怎样读例题、留下独立尝试、使用提示、定位卡点、核对后纠错、安排后续复习或求助。按当前学习情境选择具体动作，在相关说明、例题或练习之前或之后就近放置；做题前的指导不能等到题目与解答之后才出现。方法类型不设数量或比例，不把每张指导卡都改成思考题。
- **默认 A4 竖版内侧栏。**在 210 × 297 mm 纸张内安排约三分之二正文、三分之一学习栏；正文约 10.5～11 pt、侧栏约 9.5 pt。宁可增加页数，不压小字号、截断正文或把默认侧栏加在 A4 外面。宽公式与表格可以跨栏，电脑宽页版仅在需要时选择。
- **提示只留下能推进学习的文字。**每段可没有侧栏或练习；不按页凑数量，不为展示方法多样性增加任务，不塞意义不明的小问题、泛泛反思问卷、鼓励口号和重复的方法介绍。记录尝试状态、选择回查路径等流程指导只在能改变下一步行动时出现。正文照常解释清楚，检验只选少量关键题。
- **需要知识作答的侧栏有后置参考答案。**卡片中新布置的解释、判断、计算或找错任务给简短参考答案或判断要点，统一后置，以稳定编号从侧栏跳转并可返回。指导读法、记录独立完成／使用提示／卡点、安排核对与重做、暂停后续学等流程本身没有学科标准答案；不能因为它们需要动笔，就另造一道测验或编一个“正确状态”。若指导重做已有例题或练习，指向该任务及其现成解答，提供清楚的核对和返回入口。按实际要求判断，不按卡片标签豁免新增知识问题的答案。
- **不让核对文字提前剧透。**已有后置答案的侧栏只显示题目与答案入口；详细知识核对要点也放在答案区域，流程指导的操作顺序仍就近保留。来源显示简洁编号、文件名和页／节，不把内部 UUID 等实现编号写进读者讲义。
- **跳转入口清楚可辨。**侧栏使用“查看参考答案 →”，答案使用“← 返回这条提示”的可点击按钮式链接，并随输出语言翻译。PDF 与 HTML 都建立双向内部锚点，往返直接定位具体答案和原侧栏卡片，不是整章页首。PDF 检查目标页、卡片坐标与阅读缩放；整页适应会让正确坐标看起来只换了页，可采用 125% 的跳转缩放，保留可调整方式。Web 定位后突出目标，打印时不保留突出样式。跨页提示优先使用最终 PDF 的实际页序；保留正文编号时用括注区分。新增总览或重排后重新核验全部页码引用，优先可点击锚点，避免沿用旧正文页号。
- **在合适的停顿处明确提示休息几分钟。**按知识组块和练习负荷安排番茄休息点，默认可建议专注约 25 分钟后休息 5 分钟。写清触发条件、休息时长及回来后的接续动作，不能只在开头泛泛写“注意休息”。阅读页数不代表实际已用时；计时到时可先记下卡点休息，不要求为了读到指定页硬撑。
- **反馈立即进入 skill。**用户要求改学习方法、总览、布局或提示节奏时，同时修改当前产物与本 skill 的相关规则、模板或脚本；不要等“最终满意”或下一轮才创建、更新 skill。只把可复用原则写入 skill，题目特有的错误和用户局部疑问留在项目数据。
- 各种学习方法是设计依据，不能把排版成功、做题正确或用户好评写成已验证的学习效果。

## 工作步骤

### 由当前对话 AI 直接生成

读取本 `SKILL.md` 和按需选择的内置参考，直接分析用户提供的材料与学习范围，编写讲解、例题、提示和答案，再使用当前宿主可用的文档或代码工具生成 PDF。原生安装、读取文件夹或在会话中提供整个技能包，取决于客户端能力；不假定某个聊天客户端原生支持 skills。

新讲义默认重排为 A4 内栏；[references/rendering.md](references/rendering.md) 说明独立排版方式与可选脚本依赖。脚本不是唯一途径，宿主已有的排版工具同样可用。不要因为用户没有软件或 API Key 而停止技能任务，也不要把任务转交给软件操作教程。环境确实不能生成附件时说明具体能力缺口，交付已完成的可编辑内容或可导出的 HTML，不能声称已生成 PDF。

### 1. 读取真实材料，确定范围

先打开用户给出的准确路径。核对文档标题、实际内容、页数，以及课件印刷页码与 PDF 文件页序。扫描件需要渲染或 OCR；公式、划掉的错误步骤、图表需要视觉复核，不能只相信文本提取。

**手写或扫描材料：**保留原图，使用多模态模型或支持公式的 OCR 逐页完整识读中文与数学表达；上下标、分数、矩阵、根式、逻辑量词等要转为能正确排版的 LaTeX。正文、涂改和旁注分别识别，模糊处标明待核对及位置，不凭猜测补全。将转录与原图对照后再组织讲义；识读成功不等于数学正确，仍需检查前提、推导与来源之间的关系。不承诺对各种手写达到百分之百识别。

**学习页码与解释回查：**指定页码确定主学习任务，不默认禁止回查同一文件的前后页。当前页只提出问题、报出结论或省略必要前提时，先查同文件及其他已提供资料中的正式表述与解释；后文对同一结论的展开也可用于当前导入。把理解本段必需的内容补进讲义，不因讲义分节而隔断依据，也不扩大成无关章节。尊重用户明确排除某文件或要求只用指定页的限制；仍需查证时按 [references/learning-design.md](references/learning-design.md) 处理。

**多份材料一起使用时：**知识点范围应跨所有已提供文件检索并整合，不只取第一份文件。若只指定部分文件的页码，这些页是主学习材料；仍在其他已提供文件中检索相关内容作为辅助，不把其他文件整本纳入主学习范围。

在对应知识段落给简洁“资料对照”：各材料分别怎么说、其文件名与真实页／节位置、与主材料的互补关系或前提差异。存在冲突时陈述各自条件并给可核查依据，不擅自抹平；没有差异不硬编对立。没有检索到相关内容就如实说明。来源区分主材料、参考资料和按知识点找到的主题相关资料，文件页序与印刷页码分开标注；Word 分段不能冒充实际排版页。

PDF 的讲解与来源信息应足够独立阅读。宿主支持来源查看与返回时可以使用，但不要让导出的 PDF 或独立 HTML 依赖特定软件、本机路径或宿主按钮才能理解内容。

先读 [references/book-map.md](references/book-map.md) 的全书方法地图，按学习目标、材料特点、已知学习阶段和实际反馈读取对应章节参考；方法不仅用于出题，也用于组织讲解、学习过程和后续安排：

- [references/book-foundations.md](references/book-foundations.md)：第 1～6 章，学习信念、思考切换、组块、拖延、番茄工作法。
- [references/book-practice-memory.md](references/book-practice-memory.md)：第 7～12 章，练习、计划、记忆技巧与直观认识。
- [references/book-mastery-exams.md](references/book-mastery-exams.md)：第 13～18 章，深层理解、公式与迁移、自学、合作、考试。

知识库可在没有原 EPUB 时独立使用，覆盖 18 章的学习方法与应用边界，不包含整本原书。不把所有方法机械加进每份讲义。用户提供原书或要求精确引文、版本核对时再查相应章节；仅使用技能摘要时，不声称读过用户未提供的原书。通用排版与指导约定仍见 [references/learning-design.md](references/learning-design.md)。

明确区分来源原文、助教补充和发现的错误。遇到疑似错误，给可核查的证明或反例；不要照抄为学习规则。

### 2. 先写总览，再组织讲义

先产出内容地图，讲清主线和关系，再安排详细页。总览必须包含“这部分主要讲什么”的实质总结，不是仅列“先读—再练—复习”。

由 AI 根据材料内容、知识依赖和讲解需要决定章节数量、顺序与边界，不要求学习者先指定章数，也不预设数量或把章数当作讲解深度。简单内容可只成一章，复杂内容按完整概念或推理自然展开，不为凑章数拆断证明或压缩解释。为每段确定：需要理解什么、典型例子、适用条件或边界，以及学过后可以如何检验。标题页、提问页与一句结论通常和实质内容合并组织；同一来源可以支撑导入与后续详解，避免为了章节分工而让导入只剩名称和结论。

同时规划学习过程，不止划分学科章节：找出需要示范的起点、可以独立尝试的位置、失败后能回查的解释，以及适合暂停、接续或延迟复习的任务。安排可以跨章，按材料与用户目标选用，不要求每个单元走满同一流程。初学先给完整例题和必要依据；已能稳定独立完成的部分可减少逐步支撑，转向条件变化与方法选择。用户未提供学习表现时，以可试用安排和条件分支呈现，不声称已经诊断其能力、拖延或记忆弱点。

如果是已有讲义的局部修改，保留已确认的正确正文；用户只要求侧栏时，不擅自改写内容。总览加入后维护内部导航、答案引用、目录和正文页码；可以保留正文编号，并注明与 PDF 文件页序的差异。

### 3. 设计就近的学习动作

具体设计规则见 [references/learning-design.md](references/learning-design.md)。从当前情境选学习动作：新手需要怎样读懂示范，练习前需要怎样保留尝试，卡住后需要回查、换表示还是求助，核对后需要怎样修正，熟悉后哪些内容值得隔时再试。回想和新题是其中的选择，流程指导同样是有效侧栏。按需要采用“解释与完整例题 → 有限回想或重建 → 新例检验 → 延迟复习”，不要求每一节走满流程；允许无提示、无练习的自然阅读段。

侧栏写清时机、对象和可执行动作；需要留下什么时再写产物。可以是知识回答，也可以是第一处卡点、提示使用记录或下一次起点。初学例题前可写“先对照讲解读到第一个不明白的转折，标记后回查相应定义”；独立练习前可写“先留下自己的尝试再核对，卡住时记录已知、目标和第一处不确定”。这些指导不要求额外编题。针对缺口回看材料属于主动修补；短暂停顿或换解释之后仍需返回原问题验证，不能把休息当作必然得到答案的方法。跨日复习保留明确的回访对象，不用当前连续加题冒充间隔学习。

先按内容难度、推导步骤、例题理解和独立作答负荷粗估学习任务，再以约 25 分钟为可调整目标合并学习段，在完整内容的边界放侧栏休息提示。短章节可以合并，几道轻量巩固题不能单独再算一轮；不要每章必放一次，也不要因章节占满几页就自动加中途点。将估计及其依据留在可编辑记录中，不把估计当实测，更不能保证每个人都恰好用时 25 分钟。

提示写成“若距上次休息已专注约 25 分钟，休息 5 分钟；时间未到可继续”，并给就地接续动作。实际以计时和疲劳为准，计时先到可记下卡点就停，不要求等到指定页或完成整题。贯穿正文安排有意义的停顿，短尾段不为凑覆盖再插一条；不要在证明关键步骤强行断开。具体时长是可调整的学习安排，不宣称适用于所有人。

提示用稳定编号，便于用户说“4A 太早”。正文、侧栏、提示与参考解答应有层次；需要知识作答的侧栏与练习都提供后置答案及双向跳转，不把答案紧接在提问旁边破坏自测。开放知识任务给判断要点；流程记录与安排不硬编标准答案。理解不够时允许回看和提问，不要求长期盲猜，也不把卡住一概归因于缺乏自律。

### 4. 生成和检查 PDF

使用当前宿主可用的 PDF、文档、HTML/CSS 或代码排版工具，按 [references/rendering.md](references/rendering.md) 制作 A4 内栏讲义。包内 [assets/handout.css](assets/handout.css) 与两个脚本是可选辅助，不依赖软件仓库或服务；旧附栏脚本适合保留源 PDF 的特定流程，不代表默认版式，也不限制工具选择。

新讲义默认 A4 竖版，正文与侧栏都在纸张内，按实际内容自然增加页面。用户明确要求保留原 PDF 版式时，才考虑原尺寸外加侧栏；提前说明该方式会改变页面宽度。字体清楚、中文与数学符号完整比强塞进固定页数更重要。

检查分页、边界、公式、正文与侧栏对应位置、题目与答案引用、总览是否确实位于首部，以及书签和链接。抽取最终 PDF 文本并渲染查看，不能仅声称 HTML 布局正确。新增侧栏时验证原正文未丢失。检查相邻休息点之间实际安排了多少学习任务，不能以“若已专注 25 分钟”的条件句掩盖过密排程；少量重复练习应并入相邻学习段。提示贴着相关内容放在侧栏，同一停顿只显示一次。换字号或纸张后不因页数变化重新增加休息点。

按阅读顺序检查指导是否在需要时出现：练习前保留尝试、核对后纠错、停顿后接续。检查是否把所有方法都窄化为新题，或把有用的流程指导在审校时改成多余测验；同时确保流程卡没有夹带无答案的新知识问题。使用宿主支持的锚点或排版结构表达位置，不要求特定软件的数据字段。

总览标题下的学习范围保持简短；定位过程留在生成记录，不塞满首页。总览导航可逐项分页，若尾部导航单独占据近空白页，应与后续正文接续。知识标题中的公式也要排版，不能只处理正文公式。

将可编辑的讲义内容、侧栏数据及生成入口保存在交付目录中。用户正在查看导致旧 PDF 被占用时，另存新版本，不关闭用户阅读器或强行解锁。

### 5. 依据实际反馈迭代

把反馈落实到两层：

1. 当前文档：修改具体页、提示和排版，重新导出与检查。
2. 此 skill：若反馈揭示了可复用要求，同轮修改对应规则或资源；运行技能验证，脚本改动则重新执行受影响流程。

用户某一题不会，不自动成为所有未来讲义的硬性要求。区别“内容答疑”和“生成方式反馈”；后者才改变技能。明确报告具体改了哪个层面，不能把仅改了项目备注说成已改 skill。

## 交付

提供实际生成的 PDF 链接，简短说明本次变化与验证范围。若修改了 skill，链接真实的 `SKILL.md` 或具体资源。分享技能包时仅包含技能本身的文件，不夹带原教材、用户文档、完整 EPUB、绝对私有路径或临时验证产物。
